# Job Coach Pro

> **换工作时，简历写不好连面试都拿不到；面试过了不会谈薪，白涨 30% 的工资从指缝溜走。**

求职全流程教练 Skill——不只是帮你写简历，而是带你走完求职博弈的每一步：**简历优化 → 面试准备 → 谈薪博弈 → offer 对比**。

## 为什么需要这个

- 简历写了三行"负责公众号运营"，HR 直接跳过
- 面试背了一堆标准答案，一紧张全忘了
- HR 说"你的期望有点高"，你不知道怎么接
- 两个 offer 看起来差不多，不知道选哪个

大部分 AI 帮你写文字，但没人教你**怎么谈**。谈薪是博弈，不是写作——需要识别对方套路、给反制话术、解释背后逻辑。

## 四个模块

### 📝 简历优化
- STAR 法则重写每段经历
- 弱表述改强："负责"→"主导/从0到1搭建"
- 按 JD 定制，一份简历不投所有岗位
- 经历挖掘：说不清自己做了什么？帮你追问挖出来
- 覆盖转行、应届生、空窗期场景

### 🎤 面试准备
- 自我介绍模板（1-2 分钟，不废话）
- 常见问题高分回答：缺点怎么说、为什么离职
- **模拟面试模式**：扮演面试官连续追问，答完点评

### 💰 谈薪教练（核心差异化）

HR 压价 5 种套路，每种配可直接背的反制话术：

| HR 套路 | 你怎么接 |
|---|---|
| "你的期望有点高" | "方便问下薪资结构是固定为主还是绩效占比大？" |
| "现在低一点以后普调" | "每年调薪幅度大概多少？什么周期？" |
| "你上家工资多少？要流水" | "我收入构成比较复杂，基本工资部分大概是 XX" |
| "月薪 8K" | "是底薪 8K 吗？绩效占比多少？年终奖几个月？" |
| "能不能再低一点" | "我对岗位很感兴趣，想了解下薪资范围基于什么标准定的？" |

### ⚖️ Offer 对比
- 拆总包：底薪 + 绩效 + 年终奖 + 公积金 + 补贴
- 算时薪：996 的 15K 不如朝九晚五的 13K
- 初创公司风险评估：会不会倒闭？股票能不能变现？

    ├── interview-coach.md      # 面试准备 + 模拟面试
    ├── salary-negotiation.md   # 谈薪教练（核心）

## 适用场景

- 准备跳槽，不知道从哪下手
- 简历投出去没回应
- 面试紧张，想找人练
- HR 压价，不知道怎么反
- 两个 offer，纠结选哪个
