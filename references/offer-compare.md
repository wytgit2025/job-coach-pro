# Offer对比指南

## 什么时候用
用户说"两个offer怎么选""这个总包值不值""帮我看看offer"。

## 核心原则：不要只看月薪

月薪数字是最容易误导人的。真正要算的是**年总包**和**隐性成本**。

## 第一步：拆总包

把每个offer的所有收入项列出来：

| 项目 | 说明 |
|---|---|
| 基本工资 | 月固定发放，问清楚是全额还是打八折 |
| 绩效工资 | 占比多少？一般能拿满吗？还是说打折？ |
| 年终奖 | 几个月？是写在合同里还是"看公司效益"？ |
| 补贴 | 房补、餐补、交通、通讯，每月多少？ |
| 公积金 | 按什么基数交？比例5%还是12%？（差很多） |
| 股票/期权 | 有吗？归属期多久？离职了怎么办？ |
| 签字费 | 入职有没有一次性奖金？ |

**年总包 = (基本+绩效+补贴)×12 + 年终奖 + 公积金单位缴纳部分**

## 第二步：看隐性成本

数字之外，这些比月薪更影响生活质量：

| 项目 | 为什么重要 |
|---|---|
| 试用期 | 几个月？薪资打几折？淘汰率高吗？ |
| 加班强度 | 大小周？晚上几点走？周末要不要回消息？ |
| 通勤时间 | 每天多1小时通勤 = 每月多22小时 |
| 五险一金基数 | 按最低基数交和按实际工资交，退休差一倍 |
| 五险一金比例 | 公积金5%和12%，一年差上万 |
| 试用期考核标准 | 写清楚了吗？还是"看表现"？ |
| 涨薪机制 | 多久调一次？幅度多少？ |

## 第三步：算时薪

两个offer月薪差不多，但一个996一个朝九晚五，实际时薪差一倍。

> 时薪 = 月薪 ÷ (每月工作日 × 每天工时)

## 对比模板

帮用户做成这样的对比表：

```
| 项目 | Offer A（XX公司） | Offer B（XX公司） |
|---|---|---|
| 月薪 | 15K | 13K |
| 绩效占比 | 20%（基本12K） | 10%（基本11.7K） |
| 年终奖 | 2个月（看效益） | 3个月（写进合同） |
| 公积金基数 | 按最低5% | 按实际12% |
| 试用期 | 6个月打8折 | 3个月全额 |
| 加班 | 大小周 | 朝九晚六不加班 |
| 年总包（估算） | 约20万 | 约21万 |
| 时薪（估算） | XX | XX |
```

## 什么情况选A、什么情况选B

- **两个总包差不多**：选加班少的、成长空间大的
- **A比B高20%以上**：除非B有特别吸引人的点（大厂背书、转行跳板），选A
- **初创公司 vs 大厂**：初创给股票画饼要打折算；大厂给的是确定性
- **要不要为了title去小公司**：下一次跳槽时，HR看的是你做过什么、做成了什么，不是你title多高

## 初创公司风险评估

用户拿了初创公司offer时，除了算钱，还要评估这些：

| 风险点 | 怎么判断 |
|---|---|
| **会不会倒闭** | 查融资轮次——天使轮风险大，B轮以后稳一点；看现金流能撑多久（问HR：账上现金够发几个月工资） |
| **股票期权能不能变现** | 期权不是工资。问清楚：行权价多少？离职了未行权的怎么办？公司有没有回购计划？没上市的期权=纸面富贵 |
| **会不会白干** | 查一下公司口碑——脉脉、小红书搜一下员工评价；有没有大规模裁员历史 |
| **下一份工作认不认** | 初创公司的经历写在简历上，下家HR会不会质疑？如果公司小到没人听过，要靠项目成果说话，不是靠公司名 |

**初创vs大厂的决策框架：**
- 大厂 = 确定性：稳定、背书好、流程规范，但可能螺丝钉
- 初创 = 高风险高回报：可能拿到股票、做的事多，但可能半年就倒了
- 如果你现在缺钱、需要稳定 → 选大厂
- 如果你已有存款、想赌一把、想多做事 → 初创可以考虑，但要谈好现金薪资别全靠股票

## 输出格式

- 给对比表，不要给"我觉得选A"
- 列出每个offer的坑（试用期打折、公积金按最低交这种）
- 提醒用户：最终决定自己做，我帮你算清楚
